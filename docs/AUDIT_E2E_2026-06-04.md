### P1 — Funcţionalitate parţial spartă

#### P1-1. `/api/videos/[id]/status` — query lookup după upload session ID / asset ID este moartă silenţios
- **Severitate**: P1 (handle-uit graceful cu `WARN`, nu doboară endpoint-ul, dar funcţionalitatea ascunsă)
- **Detalii**:
  ```
  [Video Status] Optional status lookup failed:
  column "upload_session_id" does not exist
  column "video_asset_id" does not exist
  ```
- **Locaţie**: [app/api/videos/[id]/status/route.ts](app/api/videos/%5Bid%5D/status/route.ts#L56)
  - Linia 56: `WHERE id::text = $1 OR upload_session_id::text = $1` ← coloană inexistentă în `videos`
  - Linia 91: `WHERE id::text = $1 OR ($2::text <> '' AND video_asset_id::text = $2)` ← coloană inexistentă în `video_assets`
- **Schema reală**:
  - `video_processing_jobs`: are `asset_id` (nu `video_asset_id`)
  - `video_assets`: nu are `video_asset_id`, are `id` + `video_id`
- **Impact**: dacă utilizatorul interoghează cu un upload_session_id în loc de video.id, query-ul eşuează silent şi întoarce 404. Codul prinde excepţia şi continuă.
- **Fix propus**: Update query la `asset_id` în `video_processing_jobs`, şi eliminare clauza WHERE `video_asset_id` din `video_assets` (se caută deja după `video_id`).

#### P1-2. `/live/[id]` aruncă 500 când ID nu există (în loc de 404)
- **Severitate**: P1
- **Probe**: `GET /live/test` → 500 (după middleware rewrite la `/ro/live/test`)
- **Locaţie**: [app/[locale]/live/[id]/page.tsx](app/%5Blocale%5D/live/%5Bid%5D/page.tsx)
- **Fix propus**: în `generateMetadata` / page component, dacă DB query întoarce null → `notFound()`.

#### P1-3. `/auth` (fără locale prefix) → 404
- **Severitate**: P1
- **Detalii**: `/auth` → 404; `/ro/auth` → 307; `/en/auth` → 404
- **Cauză**: `app/auth/` există (file-system route) dar middleware-ul i18n nu adaugă locale prefix pentru această rută. `app/auth/page.tsx` coexistă cu `app/[locale]/auth/...` şi creează ambiguitate.
- **Impact**: linkuri partajate, bookmark-uri vechi, redirecturi din emailuri către `/auth?next=...` cad în 404.
- **Fix propus**: fie redirect explicit 307 `/auth → /ro/auth` în middleware, fie elimină `app/auth/` complet şi lasă doar `app/[locale]/auth/`.

#### P1-4. `/account` redirectează la `/auth?next=/account` care e 404
- **Severitate**: P1 (consecinţă directă a P1-3)
- **Probe**: `/account` → 307 `/auth?next=/account` → 404
- **Fix**: după P1-3 dispare automat.

### P2 — Best-practice / UX

#### P2-1. 5 API routes returnează 500 (în loc de 400) pentru ID-uri non-UUID
- **Severitate**: P2 (utilizatorii reali nu vor trimite "TEST", dar atacatori da)
- **Endpoint-uri afectate**:
  - `/api/challenges/[id]`
  - `/api/comments/[id]/like`
  - `/api/users/[id]/follow`
  - `/api/videos/[id]/captions/list`
  - `/api/videos/[id]/comments`
- **Cauză**: parametrul `[id]` ajunge direct în query Postgres ca UUID, fără validare → `DatabaseError: invalid input syntax for type uuid: "TEST"`
- **Fix propus**: validare cu zod sau regex `/^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i` la începutul handler-ului → return 400.

#### P2-2. `/api/auth/oauth/apple/start` returnează 503 (Apple OAuth neconfigurat)
- **Severitate**: P2 (intenţional în cod)
- **Cauză**: `APPLE_CLIENT_ID` env var lipseşte → `return NextResponse.json({ error: "Apple OAuth not configured" }, { status: 503 })`
- **Impact**: dacă butonul "Sign in with Apple" e afişat în UI, click → 503 vizibil utilizatorului.
- **Fix propus**: 
  - Opţiunea A: configurează `APPLE_CLIENT_ID` în prod env.
  - Opţiunea B: în AuthFormClient.tsx ascunde butonul Apple când env var lipseşte (necesită feature flag client-side).

#### P2-3. 14 API routes returnează 400 pentru input invalid în loc de 422
- **Severitate**: P2 (minor — diferenţa între "request malformat" şi "validation failed")
- **Exemple**: `/api/search`, `/api/products/similar`, `/api/unsubscribe`, `/api/live/streams/*`, `/api/products/[id]/reviews`
- **Notă**: comportament acceptabil pentru API REST (400 e larg). Nu e bug real, doar consistency.

#### P2-4. Tabel `_audit_canonical_cleanup_20260529` (40MB) — backup vechi neşters
- **Severitate**: P2
- **Acţiune**: `DROP TABLE _audit_canonical_cleanup_20260529` după backup verificat. Eliberează 40MB.

#### P2-5. `ae_import_jobs` 56MB / 185k rânduri — fără politică de retenţie
- **Severitate**: P2
- **Acţiune**: politică de cleanup pentru job-uri `completed`/`failed` mai vechi de 30 zile.
